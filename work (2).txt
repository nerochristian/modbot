Do not just recolor the current dashboard. Create a genuinely fresh visual direction for a Discord moderation bot dashboard.

Before coding, create a compact design plan:
- Visual identity
- Color palette with hex values
- Typography direction
- Layout system
- Dashboard density
- Signature UI element
- What makes this different from the old version

Then implement the redesign across the landing page, auth pages, dashboard shell, sidebar, topbar, cards, tables, forms, modals, charts, automod rule builder, case system, reports, appeals, settings, billing, and admin pages.

Keep all backend functionality, auth, RBAC, API routes, database models, seed data, and working dashboard actions intact. This is a visual and UX redesign, not a feature downgrade.

After implementing:
1. Run typecheck.
2. Run lint.
3. Run build.
4. Fix all errors.
5. Take screenshots or inspect the rendered app if possible.
